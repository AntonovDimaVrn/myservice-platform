# ADR-001. Монорепозиторий

Статус: принято.

## Контекст

Проект содержит документацию, контракты, несколько сервисов и локальную инфраструктуру. Их изменения часто связаны.

## Решение

Хранить проект в одном репозитории. Использовать отдельный каталог для документации, контрактов, сервисов и инфраструктуры.

## Последствия

Связанные изменения можно проверить одним PR. При росте проекта потребуется ограничить зависимости между сервисами.
