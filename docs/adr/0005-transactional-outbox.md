# ADR-005. Transactional outbox

Статус: принято.

## Контекст

Сохранение заказа и отправка события являются двумя отдельными операциями. При сбое между ними данные могут разойтись.

## Решение

Сохранять заказ и outbox-событие в одной транзакции PostgreSQL. Публиковать события отдельным worker после подтверждения транзакции.

## Последствия

Событие не теряется при временной недоступности RabbitMQ. Возможна повторная доставка, поэтому получатели проверяют `eventId`.
