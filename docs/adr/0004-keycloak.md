# ADR-004. Keycloak, RBAC и 2FA

Статус: принято.

## Контекст

Сотрудники получают доступ к контактам клиентов, расписанию и настройкам системы.

## Решение

Использовать Keycloak как Identity Provider. Использовать OpenID Connect, роли CLIENT, MASTER, OPERATOR и ADMIN. Требовать 2FA для сотрудников.

## Последствия

Пароли не хранятся в бизнес-сервисах. Каждый сервис всё равно проверяет роль и доступ к конкретному объекту.
