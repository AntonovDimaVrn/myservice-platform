# ADR-003. REST и события

Статус: принято.

## Контекст

Часть операций требует немедленного ответа. Уведомления и аналитика могут выполняться позже.

## Решение

Использовать REST для команд и запросов с немедленным результатом. Использовать RabbitMQ для событий о завершённых изменениях.

## Последствия

Контракты REST описываются в OpenAPI. Контракты событий описываются в AsyncAPI. Получатели событий должны поддерживать повторную доставку.
