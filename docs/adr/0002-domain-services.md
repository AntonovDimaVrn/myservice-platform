# ADR-002. Сервисы по бизнес-областям

Статус: принято.

## Контекст

У разных видов услуг одинаковый путь заказа, назначения и выполнения. Отдельный сервис для каждого вида создаст повторение логики.

## Решение

Разделить систему на Catalog, Orders, Scheduling, Notifications, Payments и Analytics. Вид работы хранить как тип услуги в каталоге.

## Последствия

Общая логика заказа находится в одном месте. Новая услуга добавляется без создания нового сервиса.
