# Order Service

Сервис реализует технический сценарий создания и просмотра заказа.

## Команды

Установить зависимости для разработки:

```bash
python -m pip install -e ".[dev]"
```

Запустить тесты:

```bash
pytest
```

Проверить стиль:

```bash
ruff check .
```

Применить миграцию:

```bash
alembic upgrade head
```

Сервис обычно запускается через корневой `compose.yaml`.
