# Сервисы

## Реализовано

`order-service` принимает и возвращает заказ. При создании заказа сервис записывает событие в transactional outbox. Отдельный worker публикует событие в RabbitMQ.

## Запланировано

| Сервис | Ответственность |
|---|---|
| identity | Вход, роли и 2FA через Keycloak |
| catalog | Услуги и правила расчёта цены |
| scheduling | Расписание и назначение мастера |
| notification | Уведомления клиента и мастера |
| payment | Оплата и возврат |
| analytics | Статистика заказов и выручки |

Новые сервисы добавляются только после фиксации требований и границ данных.
