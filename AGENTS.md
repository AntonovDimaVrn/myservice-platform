# Project Instructions

## Communication

- Пользователь может писать на русском или английском языке.
- Всегда отвечать пользователю на русском языке.
- Перед каждой терминальной командой кратко объяснять её назначение.
- Работать пошагово и проверять результат каждого этапа.

## Learning mode

- По умолчанию пользователь самостоятельно выполняет команды.
- Codex не выполняет команды вместо пользователя без явной просьбы.
- Объяснять новые термины простым языком.
- Не начинать разработку до согласования требований и архитектуры.

## Repository

- Основная ветка: `main`.
- Изменения выполнять в короткоживущих тематических ветках.
- Документацию хранить в каталоге `docs`.
- Архитектурные решения фиксировать в `docs/adr`.
- Перед коммитом проверять `git status` и `git diff --cached`.
