# MyService Platform

MyService Platform - pet-проект системы заказа бытовых услуг.

Система объединяет клиента, мастера, оператора и администратора. Клиент выбирает услугу, узнаёт предварительную стоимость и создаёт заказ. Оператор подтверждает заказ. Мастер получает назначение и отмечает результат работы.

Проект охватывает четыре направления:

- химчистка;
- клининг;
- дезинсекция;
- дезинфекция.

## Цель проекта

Цель проекта - пройти полный цикл системного анализа и показать связь между требованиями, процессами, архитектурой, API и кодом.

## Текущее состояние

Подготовлены требования, процессы, архитектура, API-контракты и первый технический прототип. Прототип включает создание и просмотр заказа, PostgreSQL и отправку события через RabbitMQ.

Проект не является готовой системой для реальных клиентов.

## Стек

Backend: Python 3.12, FastAPI, SQLAlchemy, Alembic.

Данные и обмен: PostgreSQL, RabbitMQ.

Инфраструктура: Docker Compose, GitHub Actions.

Документация: OpenAPI, AsyncAPI, BPMN, PlantUML, C4, ADR.

## Локальный запуск

Создайте локальный файл настроек и запустите контейнеры:

```bash
cp .env.example .env
```

```bash
docker compose up --build
```

Swagger UI: `http://localhost:8000/docs`.

RabbitMQ Management: `http://localhost:15672`.
